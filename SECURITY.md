# Security policy

## Supported versions

Security fixes are made on the latest minor release of the current major version. Upgrade to it to receive them.

## Reporting a vulnerability

Report a vulnerability privately through GitHub's private vulnerability reporting: open the **Security** tab of
the [SureQ repository](https://github.com/sureq-js/sureq) and choose **Report a vulnerability**, or go straight to
[the report form](https://github.com/sureq-js/sureq/security/advisories/new). Only the maintainer, Avinash Valluru, can see the report.

Never report a vulnerability in a public issue, pull request or discussion: that shows it to everyone before a fix
is available.

Include the affected package and version, what an attacker can do, and the smallest steps that reproduce it.

## Other bugs

Bugs that are not security issues go to the repository's [Issues](https://github.com/sureq-js/sureq/issues) tab.
