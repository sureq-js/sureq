# SureQ logo

The mark is a **Q whose tail is a check mark**: the queue, and the promise that its jobs get done.

## Files

| File | Use |
|---|---|
| `logo/sureq-horizontal.svg` | Main logo: "Sure" in ink, the Q mark in emerald. Light backgrounds. |
| `logo/sureq-horizontal-reversed.svg` | Dark backgrounds: "Sure" in white, the mark in light emerald. |
| `logo/sureq-horizontal-black.svg` | One colour: print, stamps, anywhere colour is not available. |
| `logo/sureq-symbol.svg` | The mark alone, emerald. Avatars, small spaces, social. |
| `logo/sureq-symbol-reversed.svg` | The mark alone on dark backgrounds. |
| `logo/sureq-symbol-black.svg` | The mark alone, one colour. |
| `logo/sureq-symbol-small.svg`, `-small-color.svg` | A heavier cut for 16 to 32 px. Use it below 48 px. |
| `icons/` | Favicon (`favicon.ico`, `favicon.svg`, PNGs), app icon, web manifest. |
| `build_logo.py` | Regenerates the `logo/` masters from the geometry (`python3 build_logo.py Outfit.ttf out/`). |

## Colours

| Name | HEX | RGB | Use |
|---|---|---|---|
| Emerald | `#059669` | 5, 150, 105 | The mark on light backgrounds (Tailwind emerald-600) |
| Light emerald | `#34D399` | 52, 211, 153 | The mark on dark backgrounds (emerald-400) |
| Ink | `#18181B` | 24, 24, 27 | The word "Sure" (zinc-900) |

The mark is always one colour. Do not colour the ring and the check differently: the check grows out of the ring,
and two colours would show the overlap.

## Type

"Sure" is set in Outfit SemiBold (SIL Open Font License) and converted to outlines, so no font is needed to use the
logo.

## Rules

- **Clear space:** keep at least the ring's thickness free on every side.
- **Minimum size:** the horizontal logo at 80 px wide; the mark at 16 px, using the small cut below 48 px.
- **Backgrounds:** white or light grey with the main logo; near-black with the reversed one. On photos or busy
  backgrounds, use the app icon (white mark on an emerald tile).
- **Do not:** stretch it, rotate it, add shadows or gradients, outline it, change the colours, retype "Sure" in another
  font, or put the mark next to a second Q.

## Notes

- A trademark search was not done. Do one before wide use.
